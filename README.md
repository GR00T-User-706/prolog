# Prolog – Project + Catalog

**Prolog** is your unified system to classify, catalog, and manage creative or development projects.

### Features
- 🧭 CLI, 🖥️ TUI, and 🪟 GUI modes
- 📦 Auto classification and hashing of files/folders
- 🔍 Duplicate detection
- 🧱 JSON-based live inventory
- 💡 Random idea generator
- 📝 Launches Kate automatically

### Installation
```bash
git clone <your repo>
cd prolog
pip install -e .
